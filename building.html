Building from Source¶

This page describes how to compile PVTUI from source. Note that PVTUI releases starting with v0.2.0 provide pre-built binaries for Linux x86-64.

Dependencies¶

  • C++17 compiler (e.g. GCC 8+)

  • CMake

  • FTXUI

  • EPICS Base

  • PVXS

Note

PVXS is expected to be bundled as a submodule of EPICS Base starting with EPICS Base 7.1. After that release, PVXS will not be a separate dependency.

Building¶

Clone PVTUI from GitHub and build with cmake

git clone https://github.com/BCDA-APS/pvtui
cd pvtui
cmake --preset release -DEPICS_BASE=/path/to/epics/base -DPVXS=/path/to/pvxs
cmake --build build/release

If the EPICS_BASE or PVXS environment variables are set, the corresponding flags can be omitted.

The release preset links EPICS and PVXS statically (EPICS_STATIC=ON). Add -DEPICS_STATIC=OFF to link them as shared libraries. The dev preset links them as shared libraries, builds the tests and enables the doc target (cmake --build build/dev --target doc). The dev preset requires Doxygen, Sphinx and breathe. Add -DBUILD_DOCS=OFF to skip the documentation.

PVTUI makes available several optional flags when running cmake

  • -DEPICS_BASE: (Default from environment) The path to EPICS base installation

  • -DPVXS: (Default from environment) The path to PVXS installation

  • -DEPICS_STATIC: (Default OFF) Whether or not to link EPICS statically. libevent (required by PVXS) is linked statically if libevent_core.a and libevent_pthreads.a are found, otherwise it is linked as a shared library and must be present at runtime. PVXS can provide static libevent when built with make -C bundle libevent.

  • -DFETCH_FTXUI: (Default ON) Whether or not to clone and compile FTXUI

  • -DBUILD_APPS: (Default ON) Whether or not to build applications in apps/ directory

  • -DBUILD_TESTS: (Default OFF) Whether or not to build tests in tests/ directory

  • -DBUILD_DOCS: (Default OFF) Whether or not to build Doxygen documentation

To install the cmake configuration files so other cmake projects can find the PVTUI library, set an install prefix with cmake -DCMAKE_INSTALL_PREFIX=/path/to/install/prefix and then run cmake --install <build_dir>. When FETCH_FTXUI is ON, the fetched FTXUI headers, libraries and cmake files are installed to the same prefix. Choose a prefix that does not contain another FTXUI installation.
