struct App¶

Convenience struct for managing a TUI application.

This class holds the pvtui::ArgParser, pace::Context, and ftxui::ScreenInteractive to reduce boilerplate in PVTUI applications.

Public Functions

App(int argc, char *argv[], std::initializer_list<char const*const> extra_params = {})¶

Constructs an App which internally manages a pace::Context, pvtui::ArgParser, and ftxui::ScreenInteractive.

Parameters:

  • argc – Command line argument count

  • argv – Command line arguments

  • extra_params – Additional named parameters to register with the ArgParser.

class Widget¶

A base class for all TUI widgets that interact with EPICS PVs.

This class provides a standard interface for managing PV connections, accessing PV names, and retrieving the underlying FTXUI component.

Subclassed by pvtui::BitsWidget, pvtui::ButtonWidget, pvtui::ChoiceWidget, pvtui::InputWidget, pvtui::Monitor< T >, pvtui::SliderWidget
